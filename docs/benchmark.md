## 原生 Hook 验收

使用临时目录中的同名假 `pkill` 程序（仅打印文字），在 read-only 模式下运行 Codex。前置 Hook 返回拒绝时，假程序应完全不执行。

- 首次使用 JSON deny + exit 0 时，0.162.1 仍执行了假程序。这是实际失败，不能算验收通过。
- 改为官方支持的 **exit 2 + stderr 拒绝原因** 后，Hook 确实被调用，CLI 报告 PreToolUse 拒绝，没有 command_execution 结果和假程序输出。
- 正式插件入口采用 exit 2 协议。测试只为本次调用临时信任已审阅脚本；未修改全局 hooks 或权限配置。
- 独立 CLI 回归直接检查退出码和拒绝原因，避免只测试内部函数却漏掉入口行为。

当前状态是本地源代码和临时 Hook 验收通过；用户桌面的全局插件安装/信任状态不在本次完成范围内。
